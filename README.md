# YTDLP_soft

Графический интерфейс для [yt-dlp](https://github.com/yt-dlp/yt-dlp) и ffmpeg под Windows.
Одно окно на tkinter. Собирается в один самодостаточный `.exe` со встроенным
yt-dlp — получателю ничего устанавливать не нужно.

Интерфейс на английском.

## Возможности

**⬇ Download**
- Ссылка вставляется кнопкой, из буфера или Ctrl+V (работает на любой раскладке)
- Форматы: MP4, MP3, WAV
- Разрешение до 4K, считается по меньшей стороне кадра — вертикальные видео
  (Shorts, 9:16) скачиваются в правильном качестве
- Предпочитаются кодеки h264/aac: такие файлы открываются везде без плясок
- Cookies из браузера — для видео 18+ и проверки «вы не бот»
- Плейлисты целиком, произвольное имя файла, папка запоминается
- Свой расчёт скорости и остатка: у yt-dlp ETA считается по текущему файлу
  и скачет, здесь скорость усредняется по окну в 6 секунд
- Спойлер с графиком скорости
- Кнопка обновления yt-dlp — YouTube ломает совместимость регулярно

**⚙ Convert**
- Локальный файл → MP4 / MOV / MP3 / WAV
- Четыре степени сжатия, смена разрешения и частоты кадров
- **MOV (editing)** — DNxHR, all-intra: Premiere и Resolve листают таймлайн
  без лагов, в отличие от AV1/h264 с YouTube
- Подсказка «взять последнюю загрузку» — файл не нужно указывать заново

**🖼 Image**
- Вставка скриншота из буфера (Ctrl+V), отражения и повороты, сохранение в PNG
- Заметка к картинке сохраняется в одноимённый .txt рядом
- Преобразования на чистой стандартной библиотеке, срезами байтов:
  отражение и поворот кадра 1920×1080 — 4–13 мс

**Перетаскивание** работает на всех вкладках и само разбирается в содержимом:
ссылка уходит в загрузку, видео — в конвертацию, картинка — на свою вкладку.

## Запуск из исходника

Нужен Python 3 с tkinter, `pip install yt-dlp` и ffmpeg в PATH.
Перетаскивание требует `pip install tkinterdnd2`; без него программа работает,
просто без drag-and-drop.

```
pythonw ytdlp_gui.pyw
```

Либо двойной клик по `YT-DLP GUI.bat`.

## Сборка exe

```
build_exe.bat
```

Нужен `pip install pyinstaller`. На выходе `dist/YT-DLP GUI.exe` (~24 МБ):
внутри Python, tkinter, yt-dlp и tkinterdnd2.

ffmpeg в сборку не входит — он весит больше 200 МБ на файл. Программа ищет его
рядом с собой, в папке `ffmpeg`, в PATH и в типовых местах установки, а если не
нашла — предупреждает при запуске. Без ffmpeg доступно только простое видео
среднего качества, без MP3/WAV и без вкладки Convert.

Чтобы отдать сборку «чтобы просто работало», положите рядом с exe `ffmpeg.exe`
и `ffprobe.exe` и запакуйте вместе с `README.txt`.

## Тесты

```
python tests/run_all.py
```

Открывают настоящие окна и дёргают ffmpeg, поэтому идут не мгновенно.
Проверяют расчёт скорости и остатка, счётчик роликов плейлиста, преобразования
картинки попиксельно, перетаскивание, подсветку полей, удаление недоделанного
файла при отмене и то, что закрытие окна не оставляет процессы в фоне.

## Хранение настроек

Последние папки, выбор cookies и состояние спойлера — в реестре:
`HKCU\Software\ytdlp-gui`.
