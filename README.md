# YTDLP_soft

Графический интерфейс для [yt-dlp](https://github.com/yt-dlp/yt-dlp) и ffmpeg под Windows.
Одно окно на tkinter, без зависимостей — только стандартная библиотека Python.

## Возможности

**⬇ Загрузка**
- Ссылка вставляется кнопкой, из буфера или Ctrl+V (работает на любой раскладке)
- Форматы: MP4, MP3, WAV
- Выбор разрешения (до 4K); считается по меньшей стороне кадра, поэтому вертикальные
  видео (Shorts, 9:16) скачиваются в правильном качестве
- Предпочитаются кодеки h264/aac — такие файлы открываются везде без плясок
- Плейлисты целиком, произвольное имя файла, папка запоминается между запусками

**⚙ Конвертация**
- Локальный файл → MP4 / MOV / MP3 / WAV
- Четыре степени сжатия, смена разрешения и частоты кадров
- **MOV (для монтажа)** — DNxHR, all-intra: Premiere и Resolve листают таймлайн
  без лагов, в отличие от AV1/h264 с YouTube
- Подсказка «взять последнюю загрузку» — файл не нужно указывать заново

**🖼 Картинка**
- Вставка скриншота из буфера (Ctrl+V), превью, сохранение в PNG
- Заметка к картинке сохраняется в одноимённый .txt рядом

Прогресс-бар меняет цвет: зелёный — идёт работа, красный — ошибка.

## Требования

- Windows
- Python 3 с tkinter (обычный установщик с python.org подходит)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — `pip install yt-dlp`
- [ffmpeg](https://ffmpeg.org/) в PATH — нужен для MP3/WAV/MOV и склейки видео со звуком

## Запуск

Двойной клик по `YT-DLP GUI.bat`, либо:

```
pythonw ytdlp_gui.pyw
```

Настройки (последние папки) хранятся в реестре: `HKCU\Software\ytdlp-gui`.
